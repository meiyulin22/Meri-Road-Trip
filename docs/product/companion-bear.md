## 想要的效果

小熊像在营地里自己过日子：坐在小桌后看地图、吃饭团、站着发呆，偶尔做这个、偶尔做那个，不按固定顺序；应用里真的发生事情时（出错、Meri 在回复、可以生成计划），它会停下来做出反应。

## 素材方案

不安装任何应用或依赖，用本机已有的 Python + Pillow 生成：

1. 把大图缩成真正的 64px 像素网格（约 20 色、1px 描边）。2026-10-01 的试验证明缩小后仍清楚是这只小熊。
2. 每一帧都从同一张底图逐像素改出来，因此帧与帧之间一定一致、过渡连续。
3. 小熊坐在**营地小桌**后面，桌子挡住下半身，避免画弯腿这个最难的姿势；食物暂定**饭团**。

| 动作 | 帧数 | 做法 | 预期质量 |
| --- | --- | --- | --- |
| 站着（呼吸、眨眼） | 6 | 试验已完成，眨眼待修正 | 好 |
| 坐下 | 3 | 身体分步沉到桌后 | 好 |
| 看地图（循环） | 4–6 | 原图本来就拿着地图：点头、地图轻晃、眨眼 | 最好 |
| 放下地图、拿起饭团 | 3 | 地图折到桌上，爪子举起饭团 | 一般：需要新画手臂和食物 |
| 吃（循环） | 3 | 饭团在嘴边、咀嚼鼓包、掉渣 | 最难：可爱但比原图简单 |
| 站起来 | 3 | 坐下的倒放 | 好 |
| 欢呼 / 担心 | 4–6 / 4–6 | 替换现在的 CSS 跳和抖 | 好 |
| 小桌 + 碗 | 1 张 | 从零画 | 好 |

合计约 30 帧。输出为一张精灵图 PNG（1 倍尺寸、透明背景）加一份帧清单 JSON（每个动作的行号、帧数、每帧毫秒），页面上按整数倍放大并使用 `image-rendering: pixelated`。若以后找画师精修，只需替换个别帧，帧清单格式不变。

## 行为逻辑

### 两层

| 层 | 触发 | 例子 | 优先级 |
| --- | --- | --- | --- |
| 反应 | 应用里真的发生的事 | 出错 → 担心；Meri 在回复 → 认真看地图；可以生成计划 → 欢呼 | 高，打断自由时间 |
| 自由时间 | 什么都没发生 | 有时看地图、有时吃东西、有时站着、有时发呆 | 低，随机 |

反应沿用气泡已有的状态（出错 > 思考 > 可生成）。状态消失后回到自由时间。

### 状态与过渡

```
           ┌──────────── 坐下 ────────────┐
  [站着] ◀──────────── 站起来 ────────────  [坐着]
   ├ 发呆（呼吸、眨眼）                       ├ 看地图
   ├ 欢呼（反应）                             ├ 吃饭团 ◀─ 放下 / 拿起地图 ─▶ 看地图
   └ 担心（反应）                             └ 发呆（可选，以后）
```

**物理规则：不瞬移。**想吃东西必须先坐下；坐着要欢呼必须先站起来。随机只决定“下一个目标”，调度器自动补上中间的过渡动作。

### 自由时间怎么选

每个活动结束后按权重抽下一个：

| 活动 | 权重 | 持续时间（随机） |
| --- | --- | --- |
| 看地图 | 45 | 8–20 秒 |
| 站着发呆 | 25 | 4–12 秒 |
| 吃饭团 | 20 | 5–10 秒 |
| 放空 / 什么都不做 | 10 | 10–30 秒 |

让它不机械的规则：

- 同一个活动最多连续两次，第三次重抽。
- 吃完至少 60 秒内不会再吃。
- 坐着时坐姿活动权重 ×1.5，避免一会儿坐一会儿站。
- 每段持续时间都随机，没有两个循环完全一样。
- 眨眼独立于活动，每 2–6 秒一次；看地图时偶尔点头。

### 反应怎么插进来

- 不在过渡中途硬切：等当前帧结束；坐着要欢呼就先播“站起来”。
- 出错：担心，直到错误消失。
- Meri 在回复：坐着就更认真地看地图；站着就原地做思考样子，不为一次短回复专门坐下。
- 可以生成计划：欢呼一次（跳两下）后回到自由时间；同一趟旅程不重复欢呼，除非旅程内容改变。

### 礼貌

- 标签页隐藏时暂停计时，回来接着来。
- 系统要求减少动态效果时只显示一帧（坐着看地图），不做随机活动。
- 用户 2 分钟无操作时可以更常“放空”，回来就醒（可选）。
- 小熊所在区域不接收点击，不挡任何按钮。

## 代码结构（实施时）

- **决定是纯函数**：`nextActivity(current, history, reaction, random) → { goal, steps, durationMs }`。随机数由外部传入，测试可固定它，验证“不连续三次”“60 秒饭后冷却”“不瞬移”“反应优先于自由时间”。
- **播放器只管时间和画面**：拿到步骤（如“站起来 → 欢呼”）后按帧清单播放精灵图对应行。
- **文件位置**：小熊代码到那时会有行为规则、测试、播放器、帧清单类型等多个文件，届时再新建 `src/components/companion/`，并把现有 `meri-world.tsx`、`companion-status-model.ts` 移过去；素材放 `public/companion/bear/`（`bear-sprites.png` + `bear-sprites.json`）。在此之前不预先建空目录。
